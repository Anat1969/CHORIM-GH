# החורים בתיק

**[https://chorim-gh.vercel.app](https://chorim-gh.vercel.app)**

תיק האפליקציות מול 14 תחומי הידע של מאגר הגילויים: איזה תחום חסר, באיזו פעולה, ועל מה לבנות.

- ההנחיות: [CLAUDE.md](CLAUDE.md), ומעליהן https://github.com/Anat1969/Claude-GH
- פיתוח: `npm install`, `npm run dev`
- בנייה: `npm run build` (מושך את הנתונים מהמקור, ואז בונה)
- בדיקות: `npx vite preview --port 4173 &` ואז `node tests/e2e.cjs`
- חלק מתיק העבודות: https://appofapp-gh.vercel.app
